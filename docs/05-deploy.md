# 5. Публичное демо на Cloudflare

`web/` — полностью статический сайт, без секретов, базы и серверных функций. Он показывает только вымышленные данные из `web/data.json`. Чтобы обновить цифры, снова выполните `seed`, `load`, `export` и зафиксируйте обновлённый JSON в репозитории.

Cloudflare Pages: подключить репозиторий, установить **Build command** пустым (или `exit 0`), **Build output directory** = `web`, корень репозитория — обычный. Для локального просмотра: `python -m http.server 8000 --directory web`. Сначала можно использовать бесплатный адрес `*.pages.dev`; собственный домен подключается позднее в настройках Pages. Сайт не должен получать доступ к исходным заказам реального магазина.

Проверка после размещения: открыть URL в приватном окне, изменить даты и категорию, сравнить значения «Все категории» с результатом `python -m datalab.cli report`. Публичную ссылку добавлять в README только после реального размещения и проверки.
