# 4. PySpark и сравнение

PySpark — отдельный учебный этап, выполняемый локально. Статический сайт от него не зависит. Нужны Java, свободная память и `pip install -r requirements-spark.txt` (лучше в виртуальном окружении).

```bash
python -m datalab.cli seed --output data/large --orders 10000
python -m datalab.cli load --input data/large --database data/large.db
python -m spark.compare --input data/large --database data/large.db
```

Если Spark не может привязать локальный сетевой адрес (например, в изолированном контейнере Linux), перед командой укажите `SPARK_LOCAL_IP=127.0.0.1 SPARK_LOCAL_HOSTNAME=localhost`. В Windows установите эти переменные средствами своей оболочки.

### Проверенный пример, 23 октября 2026

10 000 заказов, 15 003 позиции и 1 771 возврат. SQL и Spark получили одинаковые значения: валовая сумма 41 875 500 коп., возвраты 3 989 500 коп., чистая выручка 37 886 000 коп., 8 899 покупок, 100 повторных покупателей. В этой среде SQL-запрос занял 0,052 с, запуск Spark — 2,213 с, обработка Spark — 7,878 с. Эти времена относятся только к одному запуску в данной среде; для оценки производительности нужны повторения и указание характеристик машины.

Скрипт сначала проверяет тот же контракт CSV, затем вычисляет суммы и число повторных покупателей через Spark DataFrame API. Он сравнивает точные целые значения с SQL и завершается ошибкой, если результаты расходятся. Печатает время SQL-запроса, запуска Spark и обработки Spark отдельно. Эти цифры зависят от машины, размера данных и кэша; прямого сравнения «скорости SQL против Spark» по одним только этим замерам делать нельзя. Для честного эксперимента зафиксируйте характеристики машины и повторите запуск несколько раз.

Ограничение версии: Python-загрузка перед Spark проверяет весь снимок в памяти, поэтому это демонстрация распределённого преобразования, а не потоковая обработка произвольно большого датасета. Генератор тоже создаёт данные в памяти. Если нужна настоящая масштабируемая загрузка, этот контракт и генератор придётся переделать под потоковый ввод и внешнее хранилище.
